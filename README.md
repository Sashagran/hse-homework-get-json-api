# HSE Homework: GET-запросы и JSON

В проекте выполнены два задания:

1. Получение списка постов с JSONPlaceholder и вывод первых пяти записей (`title` и `body`).
2. Получение текущей температуры и описания погоды для указанного города через OpenWeather API.

Код написан на Python. API-ключ OpenWeather не хранится в репозитории.
