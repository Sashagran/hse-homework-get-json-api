# Проверка проекта

Проверено локально на Revision-PC, Windows, Python 3.13.13.

## Задание 1 — JSONPlaceholder

- Запрос: GET https://jsonplaceholder.typicode.com/posts
- HTTP-запрос выполнен успешно.
- JSON-ответ обработан.
- Получены и выведены ровно первые 5 записей.
- Для каждой записи выведены заголовок и тело.

## Задание 2 — OpenWeather

- Проверена логика ввода названия города.
- Автоматический тест подменяет HTTP-ответ тестовыми JSON-данными.
- Проверено извлечение названия города, температуры и описания погоды.
- Проверено, что в GET-запрос передаются параметры q, appid, units=metric и lang=ru.
- Тест: python -m unittest discover -s tests -v
- Результат: 1 тест пройден (OK).

Важно: реальный запрос к OpenWeather ещё не выполнялся, так как для него нужен личный API-ключ. Программа готова к реальному запуску после настройки переменной окружения OPENWEATHER_API_KEY.

## Дополнительные проверки

- Синтаксическая проверка всех Python-файлов через python -m py_compile прошла успешно.
- Проверена обработка ситуации, когда API-ключ не задан.
- Кодировка UTF-8 настроена для корректного отображения русского текста в Windows-консоли.
